# sort_music

sort_music provides two programs that allow you to automatically sort your mp3/flac music collection into strucured Artist/Album folders based on metadata info. sort.py loops through the files and sorts them into the correct folders, and edit.py allows you to update any false tag information. To get started, create source and destination folders anywhere on your system, upload your files into the source folder, then create a .config file in the same folder as the scripts containing the paths to the source and destination folders
